# 工作区编辑、技能启停与MCP工具开关

这些接口直接作用于 BuddyLab 的本地文件和配置。2026-10-13 `test/tool-switches.test.mjs` 八项隔离 HTTP/SDK 验收通过；测试只使用临时dataDir、受控loopback模型和stdio echo，不接生产47831、真实钥匙串或商业模型。

## 创建工作区

`POST /api/workspaces {name}` 在默认workspaceRoot父目录独占新建同名空文件夹，返回201 Workspace。name是单段名称，拒绝路径、隐藏名称、Windows保留名和特殊字符；碰撞409，不覆盖已有文件或文件夹。现有 `{path}` 入口保留，要求本机绝对路径和真实现存目录。两种输入不能混用。路径边界使用isAbsolute(relative)拒绝Windows跨盘/UNC越界，模型文件工具返回统一`/`相对路径。

## 已有文本编辑

`GET /api/workspaces/:id/file?path=...` 与 `GET /api/artifacts/:id` 返回已有预览字段，新增：

```js
{workspaceId,path,type,content,text,mimeType,bytes,size,
 sha256,editable,truncated,metadata,image?}
```

sha256取文件原bytes，覆盖Office/图片和文本；只有已有、≤256KiB、合法UTF-8、无NUL的普通文本可editable。可编辑文本返回完整正文、truncated:false，避免将预览截断段保存为全文。Office/图片返回实际提取内容或像素，editable:false，下载仍为原bytes。

`POST /api/workspaces/:id/file {path,content,expectedHash,sessionId?}`（PATCH也兼容）保存已有UTF-8文本，返回 `{workspaceId,sessionId,path,bytes,sha256,checkpointId}`。expectedHash必须是最近读取的原bytes SHA-256；过期409，保留实际外部修改。大小上限256KiB；不允许用文本保存接口修改Office/图片/二进制、读取工作区以外、写入当前模型/MCP凭证。

工作区有运行中任务时409，避免模型写入与编辑器互相覆盖。可选sessionId必须属于该工作区；关联时先捕获原文件检查点，成功后登记checkpoint_created，支持原有明确确认的恢复接口。没有session时仍必须hash匹配，但没有关联检查点。写入同目录exclusive临时文件、fsync、二次核验hash并原子rename，保留原文件权限。失败快照不可恢复；不会收养外部修改为本次afterHash。

## 技能ZIP与启停

`POST /api/skills/archive {name,base64,workspaceId?,scope?:'user'|'workspace'}` 返回201 `{skill,receipt}`。receipt含 `{name,sha256,files,unpackedBytes,importedAt,installedPath,scope,created,scriptsExecuted:false}`。ZIP限制和安全验证见技能模块专项合同。相同包同scope重复导入created:false，不覆盖用户后改的指令；仅安装数据，不自动执行脚本。

`POST /api/skills/:id/enabled {enabled,workspaceId?}` 返回技能元数据。GET list保留disabled记录；新任务只能选enabled且available的技能。启动时一次snapshot完整指令，运行中关闭开关不会改写已有system。已选技能参考资源通过host保存的snapshot读取，模型不能自己传allowDisabled或文件授权；普通load/readResource仍拒绝关闭技能。启停跨重启保存。

## MCP逐工具开关

`POST` 或 `PATCH /api/connectors/:id/tools {disabledTools:[originalToolName,...]}` 返回连接记录。保存真实MCP原始工具名，不能传生成的mcp_apiName。连接成功时校验原始名称；不必断开SDK连接。配置持久保存disabledTools，编辑完整连接配置时未传字段沿用现值。

GET/boot connector保持真实status，增加 `{toolCount,enabledToolCount,disabledTools,tools:[{name,description,enabled}]}`。断开服务没有假定工具列表。definitions过滤关闭工具；call还检查开关，旧缓存apiName也无法绕过，返回403 MCP_TOOL_DISABLED。重启加载配置不自动连接，重连后继续应用开关。禁用工具仍可在UI看到并重新启用。

## 任务描述优化

`POST /api/prompts/optimize {text,model?}` 返回 `{text,model}`。使用当前私有模型配置的独立快照，调用真实兼容模型，无tools、无session/run、无任务自动执行；缺配置返回既有明确MODEL_NOT_CONFIGURED。保留用户目标和授权范围，模型错误或空/工具回复明确失败。输入包含当前凭证时阻止发送，返回/错误脱敏；HTTP response断开取消模型请求，不把正常请求body结束当作取消。
