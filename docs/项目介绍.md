# BuddyLab 项目介绍

BuddyLab 是一个仅用于学习和非商业研究的本地 AI 工作台。它把模型对话、工具执行、文件产物、任务队列、权限确认和桌面交互放到同一个可运行项目中，帮助理解 Agent 如何从用户请求走到实际结果。

项目的重点是可核验的执行流程：使用自己的兼容模型接口，真实读取和写入工作空间，通过工具结果更新界面，并把消息、审批、问题和运行状态分别保存。模型生成的问题会暂停当前运行，用户回答后继续同一轮；没有配置服务的能力会明确显示缺口。

前端采用原生 JavaScript 和 CSS，后端采用 Node.js 与 SQLite，桌面端由 Electron 承载。文件、Office、浏览器与 MCP 各有实际执行和权限边界；原生窗口通过受限 IPC 调用必要的桌面能力。移动伴侣采用独立 HTTPS 入口、一次性配对、电脑批准和只读会话，不开放免认证公网入口。

它适合学习 Agent 工程、工具协议、状态机、桌面应用、界面复刻方法与测试策略。当前终端为单次非交互命令，部分厂商通道尚未接入，没有原版云资料库、积分、帐号或商业媒体服务。

项目参考 WorkBuddy 的可见流程与公开教程，但不是其官方产品或完整后端替代品。公开版本不打包个人数据、密钥、原安装包或缺乏明确再分发许可的原版素材。原版资源以出处、校验清单与本机导入工具提供；明确许可的第三方代码保留其许可证。
