# ADR-002：公开源码与本机参考资源分离

状态：采用。日期：2026-10-14。

## 背景

本机研究版本同时存在自主实现、具有明确许可的开源组件，以及从用户有权访问的本机产品观察或提取的参考资源。学习用途声明不能替代第三方再分发许可；公开整个工作目录还可能带出个人数据、模型配置和运行记录。

## 决策

为公开发布建立独立源码目录，保留真实运行核心、测试与公开文档；不修改用户现有本机应用和数据。具有明确许可的第三方内容保留出处与许可证。未确认再分发许可的参考内容只公开元数据和校验值，通过显式本机导入存入 Git 忽略目录，默认构建不包含这些内容。

## 影响

公开版本可以独立启动，视觉资源采用自主图标。原版效果的本机学习复现需要使用者自行确认权利和准备资源。测试、公开上传与后续提交都应检查数据排除边界；公开源码不代表原版帐号、服务或第三方内容获得商业授权。
